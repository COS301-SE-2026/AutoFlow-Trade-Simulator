## <img src="docs/images/telescope.svg" width="24" height="24" style="vertical-align: middle;"> The Problem

Entering the world of financial markets can be intimidating. Newcomers face a steep learning curve with cluttered user interfaces and complex metrics, often with no guidance. Existing platforms provide a practice account but leave users to navigate the volatile markets alone, risking discouragement and financial loss.

## <img src="docs/images/cpu.svg" width="24" height="24" style="vertical-align: middle;"> The Solution

AutoFlow is an interactive learning experience that provides a virtual trading and investment environment. It uses real market data to expose users to real-world volatility safely, with gamified features to keep them engaged and learning.

## <img src="docs/images/compass.svg" width="24" height="24" style="vertical-align: middle;"> Getting Started

<details open>
<summary><strong>1. Install Prerequisites</strong></summary>
<br>

Make sure you have Node.js, npm, and Docker installed.

</details>

<details>
<summary><strong>2. Create your .env file</strong></summary>
<br>

Create a `.env` file in the root of the repo by copying the example:

```bash
cp .env.example .env
```

</details>

<details>
<summary><strong>3. Install Dependencies</strong></summary>
<br>

Installs all Node modules and Python packages for both frontend and backend:

```bash
npm run setup
```

</details>

<details>
<summary><strong>4. Start the Database</strong></summary>
<br>

Starts the PostgreSQL and Redis Docker containers:

```bash
npm run db:start
```

</details>

<details>
<summary><strong>5. Apply Migrations and Seed Data</strong></summary>
<br>

Run migrations to create the database schema and seed it with initial data:

```bash
npm run migrate
npm run db:reset
```

</details>

<details>
<summary><strong>6. Start Development</strong></summary>
<br>

Starts the frontend and backend services concurrently.

```bash
npm run dev
```

</details>

## <img src="docs/images/square-terminal.svg" width="24" height="24" style="vertical-align: middle;"> Commands

| Command | What it does |
| :--- | :--- |
| `npm run setup` | Installs all dependencies for the project. |
| `npm run dev` | Starts the frontend and backend development servers. |
| `npm run db:start` | Starts the local PostgreSQL and Redis Docker containers. |
| `npm run db:stop` | Stops the local PostgreSQL and Redis Docker containers. |
| `npm run db:reset` | Resets the database by dropping tables, running migrations, and seeding data. |
| `npm run migrate` | Applies database migrations. |
| `npm run migrate:dev` | Creates a new database migration. |
| `npm run test` | Runs backend tests. |
| `npm run perf` | Runs backend and frontend performance tests. |
