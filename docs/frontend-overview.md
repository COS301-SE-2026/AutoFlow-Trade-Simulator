# Frontend Overview

The frontend is a Next.js app in `frontend/`.

What it does:
- Shows a home page and a demo route
- Uses small reusable UI primitives
- Calls the backend health route through an environment-driven API helper

Where it lives:
- Pages: `frontend/app/`
- UI components: `frontend/components/`
- Fetch helpers: `frontend/lib/`
- Global styles: `frontend/app/globals.css`

Smallest example:
- Open the home page at `/`
- Open the demo page at `/demo`
